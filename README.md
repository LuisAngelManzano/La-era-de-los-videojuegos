
# 🎮 Análisis de Ventas de Videojuegos (Power BI)
Desvelando 40 años de historia de los videojuegos a través de los datos.
## 📊 Descripción General
Este proyecto presenta un dashboard interactivo desarrollado en Power BI para analizar las ventas globales de videojuegos.  
El objetivo es transformar datos en información útil que apoye la toma de decisiones basada en datos.

---

## 🎯 Objetivos
- Identificar los géneros y plataformas con mejor desempeño  
- Analizar tendencias de ventas a lo largo del tiempo  
- Explorar la distribución de ventas por región  
- Destacar los videojuegos más vendidos  

---

## 🧠 Principales Hallazgos

- 🎯 **Acción es el género dominante**, con el mayor volumen de ventas globales  
- 🕹️ **PS2 es la plataforma líder**, acumulando la mayor cantidad de ventas  
- 📈 El mercado muestra un **crecimiento constante hasta ~2008**, seguido de una disminución  

---

## 📌 Métricas Clave

- 💰 Ventas Globales  
- 🏆 Juego más vendido  
- 🎯 Género más vendido  
- 🕹️ Plataforma con más ventas  

---

## 📊 Características del Dashboard

- Análisis de tendencia de ventas por año  
- Comparación de ventas por género y plataforma  
- Top 10 de videojuegos más vendidos  
- Distribución de ventas por región  
- Filtros interactivos (Género, Plataforma, Año)

---

## 🛠️ Herramientas y Tecnologías

- Power BI  
- DAX (Data Analysis Expressions)  
- Modelado de datos  
- Visualización de datos
